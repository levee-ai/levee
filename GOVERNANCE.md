# Governance

Levee uses a BDFL model. The maintainer is [@roshangardi](https://github.com/roshangardi).
The levee-ai GitHub organization is a namespace for the project and is solely
owned by the maintainer.

## Decisions

The maintainer decides scope, releases, and disputed changes. Design
discussions happen in issues. Substantial decisions are recorded in the
repository so their reasoning survives.

## Becoming a committer

There is no committer process yet. Consistent, high-quality contributions are
the path: when the project has regular contributors, this file will gain a
real committer policy, and that change will itself go through a PR.

## Changing this document

Governance changes are proposed by PR and decided by the maintainer.
